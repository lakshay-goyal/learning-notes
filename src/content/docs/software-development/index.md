Welcome to your **Software Development** knowledge base. Put all your programming learnings here.

## Suggested structure

Create subfolders or files like:

- `basics/` — language fundamentals, data structures & algorithms
- `backend/` — APIs, databases, auth
- `frontend/` — frameworks, state, performance
- `testing/` — unit, integration, e2e

## Start here

- Add a file like `software-development/clean-code.md` with:
  ```md
  ---
  title: Clean Code Takeaways
  description: Readable, maintainable code principles.
  ---
  ```
- It will appear automatically in the sidebar under **Software Development**.
