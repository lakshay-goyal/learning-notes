## Sections

- [Git](/tools/git/) — everyday commands, branching, rebasing, recovery
- [Linux](/tools/linux/) — shell, filesystem, permissions, scripting
- [Docker](/tools/docker/) — images, containers, volumes, Compose

## Add a new tool

1. Create a folder, e.g. `src/content/docs/tools/neovim/`
2. Add `index.md` inside it with `title` + `description` frontmatter
3. Add more `.md` files in that folder — sidebar updates automatically
