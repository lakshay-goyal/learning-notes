## How a research topic becomes a lesson

Research topics are produced by the harness in `.agents/`, not by hand:

```bash
node .agents/bin/deep-learn.mjs new "Topic name" --mode deep
node .agents/bin/harness.mjs check
```

That writes `docs/<slug>/` — the research package plus `learning.md`, which
declares the objectives, concepts, and multi-page plan. A second step publishes it
as learning pages:

```bash
node .agents/bin/deep-learn-visual.mjs inspect <slug>
node .agents/bin/harness.mjs check --layer=static
```

Each topic publishes one overview plus focused pages, so a lesson is a small set
of pages rather than one long one. The dashboard above groups them by topic.

## Adding a plain note

Ordinary notes that are not research topics do not need the harness. Add a `.md`
or `.mdx` file under a category folder in `src/content/docs/` with frontmatter:

```md
---
title: My Note Title
description: One-line summary.
---
```

It appears in the sidebar and search automatically.

> Tip: a topic's `index.mdx` is the overview page. Link the focused pages from it
> so the learning path is explicit rather than implied.
