## How to add a new note

1. Pick a topic folder under `src/content/docs/`, e.g. `ai-engineering/`.
2. Add a new `.md` or `.mdx` file, e.g. `rag-basics.md`, with frontmatter:
   ```md
   ---
   title: My Note Title
   description: One-line summary.
   ---
   ```
3. It appears automatically in the sidebar (autogenerate) and is searchable.

> Tip: each topic has an `index.md` landing page. Link sub-pages from there for curated learning paths.
