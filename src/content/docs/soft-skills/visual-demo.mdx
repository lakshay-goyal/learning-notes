## 1. User flow :badge[New]

`UserFlow` — a reusable step-through flow for any topic. Click a step, or press play.

<UserFlow
  title="Giving feedback, start to finish"
  steps={[
    { icon: '👂', title: 'Listen fully', text: 'No interrupting — capture the full picture first.' },
    { icon: '🪞', title: 'Reflect back', text: '“What I heard was…” — check you got it right.' },
    { icon: '📦', title: 'Use SBI', text: 'Situation → Behavior → Impact. One example, no labels.' },
    { icon: '🤝', title: 'Agree one action', text: 'End with a single next step, not five.' },
    { icon: '🔁', title: 'Follow up', text: 'Revisit once. Credit the change you see.' },
  ]}
/>

## 2. Decision flows :badge[Diagram]

`DecisionFlow` — a reusable yes/no branch for any topic. Click a branch to light up that path.

<DecisionFlow
  start="Feedback needed"
  decision="Is it timely?"
  yesLabel="Yes"
  yesResult="Use SBI now: situation, behavior, impact."
  noLabel="No"
  noResult="Note it down — wait for the right moment."
  end="One agreed action"
/>

## 5. Site graph

`starlight-site-graph` — Obsidian-style graph of your notes. Check the right sidebar on this page for the mini graph + backlinks. No code needed — it builds from your internal links automatically.

## 6. Video guide

`starlight-videos` — turn any page into a video guide by adding `video` frontmatter (needs `videosSchema` in `content.config.ts` — currently disabled to keep tag pages stable, enable when you need it). Until then, embed videos with showcases (section 10) or plain markdown links.

To make a video page later, add to its frontmatter:

```md
---
title: My talk notes
video:
  type: video
  link: https://www.youtube.com/watch?v=XXXX
  duration: 180
---
```

## 7. View modes + fullscreen reading

`starlight-view-modes` + `starlight-fullview-mode` — look for the toolbar buttons (zen / fullview) to hide sidebars for diagram-heavy reading. Try the zen URL form manually:

```text
/zen-mode/soft-skills/visual-demo/
```

## 8. Heading badges

`starlight-heading-badges` — add `:badge[Text]` to any heading, as used on sections 1–2 above.

```md

```

## 9. Quiz with progress

`starlight-quiz` — answers persist in localStorage, results aggregate at the bottom.

<Quiz title="Feedback basics">
Which of these follows SBI?

- [x] "In standup (S), you cut in twice (B), it slowed decisions (I)"
- [ ] "You are always rude in meetings"
- [ ] "Great job!"

SBI = Situation, Behavior, Impact — specific and actionable.

</Quiz>

## 13. Code fullscreen

`starlight-codeblock-fullscreen` — hover any titled block for the fullscreen button.

```js title="sbi-check.js"
function sbi(situation, behavior, impact) {
  return `[${situation}] ${behavior} → ${impact}`;
}
```

## 14. Quality + AI plugins (invisible)

- `starlight-links-validator` — build fails on broken internal links. Example valid links: [Soft Skills home](/soft-skills/) and [Tools](/tools/).
- `starlight-llms-txt` — generates `/llms.txt` and `/llms-full.txt` for AI search over your notes.
- `starlight-md-txt` — generates clean Markdown per page (e.g. this page plus `.md`) for agents.
