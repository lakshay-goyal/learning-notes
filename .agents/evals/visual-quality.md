# Visual quality review

For every substantial visual, answer:

- What learner question does this visual answer?
- Can the main relationship be understood without reading a long caption first?
- Are arrows, ordering, boundaries, labels, and state ownership technically accurate?
- Is the simplification labeled where it omits important behavior?
- Does the visual remain readable in light/dark themes and at mobile width?
- Does keyboard focus expose every interactive detail?
- Is an equivalent text structure available to assistive technology?
- Would a table, code comparison, or worked example teach this more precisely?

Reject a visual that is decorative, misleading, or illegible even if it renders successfully.
