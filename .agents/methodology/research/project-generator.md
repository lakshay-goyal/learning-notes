# Projects and active learning

Use when enabled in configuration and for all substantive new-topic packages.

Create three progressive assignments only when the topic supports them:

- **Beginner:** isolate and demonstrate the fundamental mechanism.
- **Intermediate:** integrate it into a realistic application with meaningful tests and failure handling.
- **Advanced:** introduce architectural complexity such as scale, partial failure, security, operations, or source modification.

Each project contains an objective, problem, functional and technical requirements, suggested architecture, milestones, acceptance criteria, testing strategy, common difficulties, and optional extensions. Requirements must be testable rather than aspirational.

Add at least one debugging scenario and one architecture-change scenario for deep/production/codebase modes. If source was inspected, include an exercise that names a verified path/symbol and asks the learner to trace or modify behavior.

When relevant, add one personalized application using the configured TypeScript/React/Node/mobile/AWS/Terraform/AI preferences. State problem, solution, components, approach, complexity, prerequisites, and learning outcome. Do not force unrelated infrastructure into an exercise.
