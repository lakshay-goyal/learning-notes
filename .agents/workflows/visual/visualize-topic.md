# Visualize a topic or concept

Read the relevant research sections and identify the exact question the visual must answer. Select the representation using `rules/diagram-selection.md`, sketch the information hierarchy, then implement the smallest accurate visual with an accessible text equivalent.

Check the diagram against source directionality, state ownership, timing, failure behavior, and security boundaries. Test dark/light themes, narrow screens, keyboard interaction, and reduced motion. Add the source-to-destination mapping to the topic coverage map.
