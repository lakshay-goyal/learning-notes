- [`repository-analysis.md`](repository-analysis.md): repository selection, source inspection, and execution traces
- [`technical-teaching.md`](technical-teaching.md): lesson construction and examples
- [`production-analysis.md`](production-analysis.md): material production dimensions and trade-offs
- [`project-generator.md`](project-generator.md): projects, exercises, and personalized applications
