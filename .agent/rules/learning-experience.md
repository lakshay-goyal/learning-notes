# Learning experience rules

Every substantial topic supports four access levels, proportionate to the subject:

1. **Quick recall:** definition, problem, mental model, one useful visual or compact representation, three takeaways, and use conditions.
2. **Visual understanding:** architecture/control/data flow, ordered mechanism, annotated example, relationships, and trade-offs.
3. **Complete understanding:** implementation, internals, failures, security, production concerns, alternatives, inspected repositories, and primary references that the research actually supports.
4. **Active recall:** questions that require retrieval, prediction, debugging, application, architecture, or trade-off reasoning before answers are revealed.

Reduce visible cognitive load with hierarchy and disclosure; do not delete important knowledge. The default scan path should be short, while full research remains reachable through deep dives and `/research/` source routes.

Teach in dependency order. Define terminology before relying on it. Explain what a visual answers immediately before or after it. Do not create empty template sections or force the same page outline onto unrelated concepts.
