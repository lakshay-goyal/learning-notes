# Audit the knowledge base

Run strict visual validation for all topics and build the site. Then review:

- topic IDs and routes are unique and stable;
- coverage maps include every research level-two heading;
- internal relationships resolve and express real technical meaning;
- research routes render the original Markdown;
- quick recall is self-contained without pretending to be complete;
- deep material, limitations, primary sources, and personal findings remain reachable;
- recall prompts test the actual objectives;
- browser progress shows honest empty states and never claims synchronization.

Record unresolved issues instead of passing them through optimistic wording.
